          批次最佳化將會對選定範圍內的所有應用程式逐一執行 AOT 編譯。過程可能會耗時較久（數分鐘至數十分鐘不等），期間手機 CPU 運算頻率升高可能伴隨微發熱現象。請確保手機電量充足（建議 > 50%）或接上充電器，並保持 USB 連線穩定。

    • 
          
  • 檢視內容：讀取 /data/misc/profman/<package>.txt 行數，大於 0 行代表已有熱點資料。
    • 
          
  • 智慧顯示：有 Profile 者按鈕顯示 speed-profile 編譯；無 Profile 者自動轉為 speed 編譯。
